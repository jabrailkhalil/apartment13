# Apartment 13 (Квартира 13)

Атмосферный 3D психологический хоррор-квест от первого лица в браузере на Three.js.

## 🎮 Описание игры
События разворачиваются в таинственной советской квартире номер 13 в пятницу, 13-го числа. Главный герой просыпается утром, собирается на работу, но вскоре получает странное уведомление об увольнении и отправляется в магазин за продуктами. По возвращении домой и включении телевизора объявляется режим гражданской обороны: город охватил зомби-апокалипсис. Игроку предстоит забаррикадироваться, запастись едой и выживать.

## 🚀 Запуск игры
Игра работает прямо в браузере без установки дополнительных серверов:
1. Скачайте репозиторий или откройте папку проекта.
2. Запустите файл `index.html` в любом современном веб-браузере (Chrome, Edge, Firefox, Opera).

Для локальной разработки также можно запустить `python -m http.server 8000` в папке проекта и открыть `http://localhost:8000`.

## Управление

| Действие | Клавиши |
| --- | --- |
| Ходить | WASD или стрелки |
| Осмотреться | Мышь |
| Взаимодействовать | ЛКМ или F |
| Встать с дивана / стула | F |
| Пауза | Esc |

Если браузер не поддерживает захват мыши, игра автоматически включает осмотр с зажатой правой кнопкой мыши. При переключении окна движение сбрасывается, а игра встаёт на паузу. Нажмите «Продолжить», чтобы вернуться.

## Текстуры окружения

Обои и плитка привязаны к координатам комнаты: узор сохраняет размер и продолжается на отдельных участках стены вокруг окон и дверей. Снег создаётся процедурно с совпадающими краями; дорога и тротуары используют одинаковый масштаб. Небо представляет собой единую сферу, а дальние здания уходят в туман.

Обои `assets/wallpaper-seamless.jpg` подготовлены встроенным imagegen по исходному цветочному узору. Исходные изображения сохранены в `assets.js`; точный запрос записан в `assets/wallpaper-seamless.prompt.txt`. Копия обоев в `wallpaper-asset.js` позволяет запускать игру через `file://`. После изменения JPG обновите её командой `node tools/embed-wallpaper.js`.

## Проверки для разработки

Для автоматических проверок нужен Node.js 18 или новее; устанавливать пакеты не требуется:

```sh
node --test tests/surfaces.test.js
```

Проверяются непрерывность и масштаб UV на стенах, совпадение граничных пикселей снега, резервное управление мышью, сброс движения и пересекающиеся коллизии мебели. Визуальные изменения дополнительно нужно смотреть в самой игре.

## 🛠 Технологии
- **Three.js** (3D рендеринг, освещение, тени, физические коллизии)
- **HTML5 Canvas & Web Audio API** (синтез звуков, процедурные текстуры хвои и окружения)
- **Vanilla JavaScript (ES5)** (совместимость и производительность)
- **CSS3 CRT & Vignette FX** (эффект ретро-монитора и кинематографичной атмосферы)
